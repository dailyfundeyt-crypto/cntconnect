# 🎵 Spark – BrainFM Audio: AI Music Generation Prompts

> **Ziel:** Atmosphärische Instrumentalmusik ohne Stimme, die als Hintergrundmusik
> für fokussiertes Arbeiten, Meditation, Schlaf und kreative Zustände dient.
> Alle Prompts sind für **Suno AI**, **Udio**, **Stable Audio** und **AudioCraft** optimiert.

---

## 🛠️ Empfohlene Tools

| Tool | Stärken | Link |
|---|---|---|
| **Suno AI** | Bester Gesamtklang, sehr atmosphärisch | suno.ai |
| **Udio** | Sehr präzise Stil-Kontrolle, Layering | udio.com |
| **Stable Audio** | Lange Loops (bis 3 Min), Open Source | stability.ai |
| **Meta AudioCraft** | Lokal ausführbar, lizenzfrei | github.com/facebookresearch/audiocraft |

> **Wichtig für alle Prompts:** Füge immer hinzu: `no vocals, no lyrics, no voice, no singing, instrumental only`

## 📋 Quick-Copy Template

Kopiere dieses Template und fülle die `[...]` aus:

```
[Stil / Genre], [Instrument 1], [Instrument 2], [Atmosphäre],
[Zeitgefühl / Energie], [Tempo in BPM], [Tonart optional],
[Referenzkünstler optional], [spezielle Textur oder Effekt].

```

## 🔗 Weitere Tipps

- **Länge:** Generiere immer **2–3 Minuten** und loope nahtlos im Browser mit der Web Audio API.
- **Varianten:** Generiere 3–5 Varianten pro Prompt und wähle die beste aus.
- **Lizenz:** Suno AI Pro / Udio Pro erlauben **kommerzielle Nutzung**.
- **Format:** Exportiere als **MP3 (192kbps)** oder **OGG Vorbis** für kleine Dateigröße im Web.
- **Hosting:** Lege die Dateien in `public/audio/brainfm/` im Spark-Projekt.
